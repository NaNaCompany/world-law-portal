# 세계 법령 자료실

공식 법령의 원문 텍스트를 제공하는 독립 자료실입니다.

- 공개 주소: https://nanalab.kr/world-law-portal/
- 배포: GitHub Pages, `main` 브랜치 루트. `.nojekyll` 사용.
- 법령은 원문 언어 그대로 제공합니다. 한국어·English·中文·Español 선택은 화면 언어만 바꿉니다.
- 법령별 제목·판본·공식 출처·재이용 조건·원본 해시를 보존합니다.
- 법령별 메인 복귀, 이전/다음 탐색, `More Apps` 링크를 제공합니다.
- PDF 다운로드와 이미지 파일은 제공하지 않습니다. 이미지로만 제공되는 별표·서식은 제외 사실과 공식 원문 링크를 표시합니다.

## 범위와 검증

초기 공개판은 한국 현행법령 텍스트 2,609건과 기존 글로벌 문서 34건을 포함합니다. 전 세계 또는 한국의 모든 법령을 확보한 데이터베이스가 아닙니다. 한국의 공식 현행 목록은 기준일 2026-10-25의 5,628건이며, 수집은 계속 진행합니다. 실제 공개 수와 범위는 각 목록과 `sitemap.xml`, `publication.json`을 확인합니다.

원본 HTML의 보존 텍스트와 기존 PDF 추출 캐시를 검증해 HTML을 생성합니다. 요약·번역·법조문 재작성은 하지 않습니다. 추출 과정의 표·다단 배치·줄바꿈·빈 쪽·읽기 순서는 원본 문서와 다를 수 있습니다. 부분 수집 문서는 누락 사실을 표시합니다. 정확한 효력·판본·별표·서식은 문서별 공식 출처에서 확인합니다.

본문은 공식 자료의 원문입니다. 기관 홈페이지의 디자인·로고·사진·민간 해설을 재배포하지 않습니다. 소스 수집 과정의 PDF 복제본은 텍스트 검증 후 폐기하며, 원본/텍스트 SHA-256과 출처는 유지합니다.

## 자동 추가

로컬 수집 파이프라인은 새로 확보한 텍스트의 권리·출처·본문·링크·태그를 확인한 뒤 생성 파일을 이 저장소에 반영합니다. 각 반영에는 전체 언어별 메인과 상세 경로를 포함한 사이트맵을 갱신합니다. Pages 브랜치 빌드 빈도를 고려해 검증된 추가분을 묶어 반영합니다. 인증값·원본 연구 HTML·수집 로그는 이 저장소에 포함하지 않습니다.

모든 메인과 하위 법령 페이지에 NaNa Lab의 GTM·GA4·AdSense loader·Cloudflare Web Analytics 코드를 포함합니다. 코드 검증은 실제 광고 송출이나 분석 서비스 수신을 인증하지 않습니다.

## 라이선스

자체 작성한 인터페이스와 검사 코드의 조건은 `LICENSE.md`를 따릅니다. 법령 원문은 각 문서에 표시한 공식 출처와 관할별 재이용 조건을 따릅니다. 자체 코드의 라이선스를 제3자 원문 전체에 적용하지 않습니다.

## 2026-11-09 추가 공개 묶음

기존 문서를 보존하면서 174개 원문 문서를 추가했습니다. 미국 2024년판 법전의 장 단위 60개, 중국 법률 6개, 일본 법률 94개, 신규 유럽 14개국의 선정 법령/헌법 14개입니다. 국별 전체 법령이나 최신성의 완전성을 뜻하지 않습니다. 유럽 신규 관할은 AD, BA, CZ, GR, HR, IE, IS, LV, NO, PL, PT, RS, SE, SI입니다. 그리스는 공식 HTML 124개 조문으로, 해당 출처가 제공하지 않는 서문은 미포함임을 상세 페이지에 명시했습니다.

추가 문서의 출처, 판본, 재이용 조건, 원본 및 텍스트 해시는 `additions-catalog.json`에 있습니다. `catalog.json`은 초기 34개 자료의 목록이며 전체 현황 목록이 아닙니다. 현재 페이지 수는 `publication.json`과 사이트맵을 확인하세요.

추가 작업은 검증된 외부 입력 JSON을 `node scripts/add-verified-laws.mjs <input.json>`에 전달합니다. 원문 수집본과 작업 로그는 저장소 밖에 보관합니다. 입력의 전체 본문과 필수 출처·재이용·완전성 검증 자료가 필요하며, 기존 ID·공식 URL·텍스트 해시·동일 국가 제목을 대조합니다. `COLLECTION_TIMESTAMP`로 검증된 UTC 수집 묶음 시각을 지정할 수 있습니다.

공개 전 `node scripts/validate-additions.mjs`와 `node scripts/validate-published.mjs`를 모두 실행합니다. 두 검사는 추가 원문 해시, 모든 언어의 목록/사이트맵, 내부 링크, 광고·추적 태그를 검사합니다. 한국 외부 저장소로 이전한 리디렉션 5,628개는 포털의 canonical 사이트맵에서 제외합니다. 브라우저 화면 렌더링과 실제 광고/분석 수신은 이 정적 검사로 인증하지 않습니다.

## 2026-11-09 두 번째 추가 공개 묶음

147개 문서를 추가했습니다. 미국 2024년판 법전 장 단위 33개, 중국 법령 9개, 일본 법령 96개, 유럽 9개 문서입니다. 신규 관할은 BG, CH, DK, EE, FI, LU, RO 7개국이며 스웨덴 언어법도 추가했습니다. 오늘 두 묶음의 추가 문서 수는 총 321개입니다. 국가별 전체 법령 수집을 뜻하지 않습니다.

판본 차이를 상세 페이지에서 확인해야 합니다. 에스토니아 헌법은 2015-08-13부터 2025-07-08까지의 과거판이며 현행본이 아닙니다. 중국 상표법은 2027-01-01 시행 예정판입니다. 일본 「麻薬及び向精神薬取締法」은 별표의 법정 그림 1개가 제외된 부분 텍스트 재현이며 누락 위치를 명시했습니다. 스위스의 비공식 간행물 고지와 룩셈부르크의 CC BY 4.0·비공식 통합본 고지를 유지합니다.

## 2026-11-09 세 번째 추가와 일본 구조 검토 안내

미국 2024년판 법전 장 단위 19개, 벨기에 헌법 1개, 리히텐슈타인 법령 2개, 이탈리아 헌법 개정법 원문판 2개, 스위스 주요 법령 11개로 총 35개 문서를 추가했습니다. 신규 관할은 BE, IT, LI이며 국가별 전체 법령 수집을 뜻하지 않습니다. 입력의 날짜·판본과 필수 재사용 고지를 보존합니다. 공식 원문 자체에 대체문자가 있는 미국 문서는 추정 복원하지 않고 이번 묶음에서 제외했습니다.

이전 추가 묶음의 일본 190개 문서는 구조 검토 중입니다. 일부 문서에서 원문 데이터의 부칙 개정법번호·발췌 속성, 병합표 및 기타 구조정보가 완전히 표시되지 않은 점을 확인했습니다. 해당 상세 페이지와 4개 언어 목록에 검토 중임을 표시하고, 문서별 확인된 제한사항과 공식 원문 링크를 제공합니다. 이번 표시 변경은 법문을 수정하지 않습니다. 법적 판단에 사용할 때는 공식 원문의 전체 구조와 효력·판본을 확인해야 합니다.

CNIPA 출처의 기존 특허법·상표법 2개 문서는 사이트 저작권 선언과 적용범위의 불확실성을 재사용 안내에 보강했습니다. 법률 텍스트의 저작권 제외를 모든 사이트 조건에 대한 포괄적 상업 이용허락으로 표시하지 않습니다. `scripts/update-law-provenance.mjs`와 `scripts/mark-law-structure-review.mjs`는 검토된 입력만 받아 본문 외 안내를 수정하며, 법문 영역의 불변을 검사합니다.
