# 세계 법령 자료실

공식 법령의 원문 텍스트를 제공하는 독립 자료실입니다.

- 공개 주소: https://nanalab.kr/world-law-portal/
- 배포: GitHub Pages, `main` 브랜치 루트. `.nojekyll` 사용.
- 법령은 원문 언어 그대로 제공합니다. 한국어·English·中文·Español 선택은 화면 언어만 바꿉니다.
- 법령별 제목·판본·공식 출처·재이용 조건·원본 해시를 보존합니다.
- 법령별 메인 복귀, 이전/다음 탐색, `More Apps` 링크를 제공합니다.
- PDF 다운로드와 이미지 파일은 제공하지 않습니다. 이미지로만 제공되는 별표·서식은 제외 사실과 공식 원문 링크를 표시합니다.

## 범위와 검증

초기 공개판은 한국 현행법령 텍스트 2,609건과 기존 글로벌 문서 34건을 포함합니다. 전 세계 또는 한국의 모든 법령을 확보한 데이터베이스가 아닙니다. 한국의 공식 현행 목록은 기준일 2026-10-25의 5,628건이며, 수집은 계속 진행합니다. 실제 공개 수와 범위는 각 목록과 `sitemap.xml`, `publication.json`을 확인합니다.

원본 HTML의 보존 텍스트와 기존 PDF 추출 캐시를 검증해 HTML을 생성합니다. 요약·번역·법조문 재작성은 하지 않습니다. 추출 과정의 표·다단 배치·줄바꿈·빈 쪽·읽기 순서는 원본 문서와 다를 수 있습니다. 부분 수집 문서는 누락 사실을 표시합니다. 정확한 효력·판본·별표·서식은 문서별 공식 출처에서 확인합니다.

본문은 공식 자료의 원문입니다. 기관 홈페이지의 디자인·로고·사진·민간 해설을 재배포하지 않습니다. 소스 수집 과정의 PDF 복제본은 텍스트 검증 후 폐기하며, 원본/텍스트 SHA-256과 출처는 유지합니다.

## 자동 추가

로컬 수집 파이프라인은 새로 확보한 텍스트의 권리·출처·본문·링크·태그를 확인한 뒤 생성 파일을 이 저장소에 반영합니다. 각 반영에는 전체 언어별 메인과 상세 경로를 포함한 사이트맵을 갱신합니다. Pages 브랜치 빌드 빈도를 고려해 검증된 추가분을 묶어 반영합니다. 인증값·원본 연구 HTML·수집 로그는 이 저장소에 포함하지 않습니다.

모든 메인과 하위 법령 페이지에 NaNa Lab의 GTM·GA4·AdSense loader·Cloudflare Web Analytics 코드를 포함합니다. 코드 검증은 실제 광고 송출이나 분석 서비스 수신을 인증하지 않습니다.

## 라이선스

자체 작성한 인터페이스와 검사 코드의 조건은 `LICENSE.md`를 따릅니다. 법령 원문은 각 문서에 표시한 공식 출처와 관할별 재이용 조건을 따릅니다. 자체 코드의 라이선스를 제3자 원문 전체에 적용하지 않습니다.
